# Capture The Flag (CTF) & Forensic Challenge Archive

Technical writeups, challenge blueprints, and forensic artifacts authored for security engineering competitions and training simulations.

Maintainer: **@stefanutc1** | Classification: **TLP:CLEAR** | License: **MIT**

---

## 1. Challenge Format & Standardized Template

All challenge documentation follows the structured format defined in [`template.md`](template.md):

* **Category**: Forensics, Web Security, Reverse Engineering, Cryptography, Network Analysis.
* **Difficulty**: Easy, Medium, Hard, Insane.
* **Objective**: Technical problem statement and mission scope.
* **Artifacts**: PCAP files, memory dumps, disk images, or deobfuscated scripts with SHA-256 checksums.
* **Walkthrough**: Step-by-step technical methodology from initial triage to flag extraction.
* **Remediation**: Defensive engineering controls that prevent the underlying vulnerability.

---

## 2. Evidence Integrity

Challenge artifacts adhere to ISO/IEC 27037:2012 preservation guidelines with pre-computed SHA-256 hashes recorded in evidence manifests.
