# Homelab Custom SaaS & Microservice Suite

In-house software built from scratch to replace third-party self-hosted applications and serve as portfolio SaaS foundations.

---

## 📂 Architecture & Replaced Tools

| Tool Replacement | Custom Service | Architecture / Stack | Readiness |
| :--- | :--- | :--- | :---: |
| **Uptime Kuma** | **PulseGuard** | Node.js / Go Heartbeat Engine + SQLite + Public Status Pages | Tier 1 (Immediate) |
| **IT-Tools** | **DevForge** | Vue 3 + TypeScript Client-side Crypto & Token Utilities | Tier 1 (Immediate) |
| **ChangeDetection.io** | **PriceScope** | Python / Node DOM & Price Tracker + Webhook Alerts | Tier 1 (Immediate) |
| **Gitea** | **GitForge Lite** | Go / Node Git HTTP Smart Protocol + Syntax Explorer | Tier 2 (Masterclass) |
| **Woodpecker CI** | **PipeRunner** | Autonomous Pipeline Engine + Docker Step Sandboxing | Tier 2 (Masterclass) |

---

## 🚀 Quickstart & Testing Locally

You can test all 5 tools interactively right in the frontend dashboard:

```bash
cd homepage
npm run dev
```

Then navigate to the **`custom saas suite`** tab in the top navigation bar!
