# Plan 9 from Bell Labs (VM 215)

* **Host**: Node 1 (Intel i3-10100F x86_64)
* **VMID**: VM 215
* **Name**: `plan9`
* **vCPU**: 1 Core
* **RAM**: 512 MB
* **Storage**: 12 GB NVMe disk (`local-lvm:vm-215-disk-0`)
* **IP**: `192.168.1.215`
* **Role**: Research operating system developed by Bell Labs (Ken Thompson, Rob Pike, Dennis Ritchie). Embodies the pure philosophy that "everything is a file" with the 9P distributed network protocol, per-process private namespaces, dynamic resource binding, and the minimalist Rio windowing interface.
