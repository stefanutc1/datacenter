# Redox OS 0.9.0 (VM 219)

* **Host**: Node 1 (Intel i3-10100F x86_64)
* **VMID**: VM 219
* **Name**: `redox`
* **vCPU**: 2 Cores
* **RAM**: 2,048 MB (2 GB) [VirtIO Ballooning: 1,024 MB (1 GB)]
* **Storage**: 10 GB NVMe disk (`local-lvm:vm-219-disk-0`)
* **IP**: `192.168.1.219`
* **Role**: General-purpose microkernel operating system written entirely in Rust. Inspired by Minix and Plan 9, featuring RedoxFS, per-process namespaces, memory safety guarantees, and a modern microkernel driver architecture.
