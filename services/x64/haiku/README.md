# Haiku OS R1/beta5 (VM 214)

* **Host**: Node 1 (Intel i3-10100F x86_64)
* **VMID**: VM 214
* **Name**: `haiku`
* **vCPU**: 2 Cores
* **RAM**: 2,048 MB (2 GB) with VirtIO dynamic memory ballooning to 1,024 MB (1 GB)
* **Storage**: 20 GB NVMe disk (`local-lvm:vm-214-disk-0`)
* **IP**: `192.168.1.214`
* **Role**: Open-source desktop operating system inspired by BeOS. Features a pervasive object-oriented C++ API, pervasive multithreading, unified metadata database file indexing with the OpenBFS filesystem, and responsive modular micro-app design.
