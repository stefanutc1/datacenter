# Security Onion / Wazuh SIEM Platform (VM 217)

* **VMID**: VM 217
* **Name**: `securityonion`
* **vCPU**: 4 Cores
* **RAM**: 8,192 MB (8 GB) [VirtIO Ballooning: 4,096 MB (4 GB)]
