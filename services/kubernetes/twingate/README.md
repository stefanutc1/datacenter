# Twingate Zero-Trust Network Access (ZTNA) Connector

* **Cluster Target**: Hybrid Kubernetes Fleet (Node 1 Talos/k0s + Node 3 UTM ARM64)
* **Namespace**: `twingate`
* **Role**: Peer-to-peer encrypted remote connector granting least-privilege authenticated access to cluster services without exposing public IP addresses or managing port forwarding on the perimeter firewall.
